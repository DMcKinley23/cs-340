# cs-340
CS-340 Client/Server Development Portfolio

How do you write programs that are maintainable, readable, and adaptable?

I try to write programs in a way that makes them easy to understand and update later. One of the biggest examples from this course was creating the CRUD Python module in Project One and then reusing it in Project Two. Instead of rewriting database code throughout the dashboard, I was able to keep the database functions in one place and call them when needed. This made the code more organized, easier to troubleshoot, and easier to modify. In the future, I could reuse the same CRUD module for other applications that need to connect to a MongoDB database.

How do you approach a problem as a computer scientist?

When working on the Grazioso Salvare dashboard, I broke the project into smaller pieces and solved each part one step at a time. I first made sure the database connection worked, then tested the CRUD module, and finally connected everything to the dashboard components. This project was different from many previous assignments because it required several technologies to work together instead of focusing on a single program. In the future, I would continue using this approach by carefully reviewing requirements, designing a solution before coding, testing frequently, and making changes as needed.

What do computer scientists do, and why does it matter?

Computer scientists solve problems by designing software and systems that help people work more efficiently. In this project, the dashboard allows Grazioso Salvare to quickly view and filter rescue animal data without manually searching through records. The dashboard presents information in a way that makes decision making easier and helps users find the data they need more efficiently. Projects like this show how software can help organizations save time, improve accuracy, and make better use of their data.
